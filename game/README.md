# 游戏文件放这里

这个目录在仓库里是空的 —— **本仓库不含游戏本体**。

请把《东方虹龙洞》**v1.00a 原版**的以下文件复制到本目录（就是这个 `game/` 文件夹，不要再套一层子目录）：

```
game/
├── th18.exe      ← 必需
├── th18.dat      ← 必需
├── thbgm.dat     ← 必需
└── custom.exe    ← 可选（改分辨率/按键的设置程序）
```

放好后双击仓库根目录的 `启动TH18mod.bat`，启动器会自动校验。

**版本必须对得上。** thcrap 靠 exe 的 SHA256 认版本，认不出就什么补丁都不会打：

| 文件 | SHA256 |
|---|---|
| `th18.exe` | `5aeb74b19939a29a8cf06e4fe7777aaf9139e93478507e039f43318171020e9f` |
| `custom.exe` | `6b287f8826bf703ac82bf97ac65f7343d32dfffacc875a20fd84a1a0bae7a8c1` |

Steam 版、汉化版、以及任何被改过的 exe 都**不行**。详见 [`../docs/setup.md`](../docs/setup.md)。
